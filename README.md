# 台灣電輔折疊單車旅行地圖

私人互動網站，為兩人各騎一台電動輔助折疊單車、每車兩顆電池設計。

## 內容

- 26 條台鐵銜接路線，單日最長 68 公里
- 地區、距離與路線類型篩選
- Leaflet + OpenStreetMap 互動地圖
- 補給、休息、景點、美食及重要座標
- 台鐵攜車與兩鐵人車同行規定
- 各路線規劃 GPX 下載
- 手機與桌面響應式介面

## 檔案

- `index.html`：網站頁面
- `styles.css`：視覺與響應式版面
- `data.js`：路線、景點及座標資料
- `app.js`：地圖、篩選、詳情與 GPX 功能
- `.openai/hosting.json`：ChatGPT Sites 部署設定

## 注意

網站內的路線線段與 GPX 是行前規劃軌跡，不是即時導航。出發前仍須確認道路施工、天候、台鐵當日指定班次與自行車額度。
