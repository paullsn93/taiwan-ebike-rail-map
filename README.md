# 台灣電輔折疊單車旅行地圖

互動網站：[直接開啟](https://taiwan-ebike-rail-map.paullsn93.chatgpt.site)

為兩人各騎一台電動輔助折疊單車、每車兩顆電池設計的台灣單車旅遊規劃工具。

## 目前內容

- 36 條一日路線，單條不超過 70 公里
- 地方政府官方路線、官方路網延伸與本站規劃的清楚來源標示
- 地區、距離、路線類型與資料來源篩選
- 實際軌跡、景點及重要節點座標、補給、美食與台鐵銜接資訊
- 台鐵折疊裝袋及不折疊整車同行限制
- 個人 GPX 多檔匯入、地圖顯示、備份與刪除

## 個人路線隱私

個人 GPX 只保存在匯入者目前使用的瀏覽器（localStorage），不會上傳到網站或顯示給其他訪客。清除瀏覽器網站資料前，請先使用「備份我的路線」。

## 檔案

- `index.html`：頁面結構與內容
- `styles.css`：桌機與手機版樣式
- `data.js`：路線、節點與來源資料
- `app.js`：地圖、篩選、GPX 匯入與互動功能
