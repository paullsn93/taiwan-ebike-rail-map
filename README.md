# 台灣電輔折疊單車旅行地圖

互動網站：[直接開啟](https://taiwan-ebike-rail-map.paullsn93.chatgpt.site)

為兩人各騎一台電動輔助折疊單車、每車兩顆電池設計的台灣單車旅遊規劃工具。

## 目前內容

- 40 條一日路線，單條不超過 70 公里
- 地方政府官方路線、官方道路資料、官方路網延伸與本站規劃的清楚來源標示
- 地區、距離、路線類型與資料來源篩選
- 實際軌跡、景點及重要節點座標、補給、美食與台鐵銜接資訊
- 台鐵折疊裝袋及不折疊整車同行限制
- 個人 GPX 多檔匯入、地圖顯示、備份與刪除

## 花東四小橫

已加入影片所介紹的四條海岸山脈橫越路線：

1. 光豐公路（台11甲）：光復車站 → 豐濱鄉公所，約 19.2 km
2. 瑞港公路（花64）：瑞穗車站 → 長虹橋／台11線，約 25.7 km
3. 玉長公路（台30）：玉里車站 → 寧埔／台11線，約 22.3 km
4. 東富公路（台23）：富里車站 → 東河橋遊憩區，約 46.4 km

四條路線均可在網站詳情視窗下載 GPX。官方網站多提供道路或景點資訊，未完整提供四條官方 GPX，因此下載檔明確標示為依道路中心線製作的規劃軌跡，不冒充官方實騎紀錄。

## 個人路線隱私

個人 GPX 只保存在匯入者目前使用的瀏覽器（localStorage），不會上傳到網站或顯示給其他訪客。清除瀏覽器網站資料前，請先使用「備份我的路線」。

## 檔案

- `index.html`：頁面結構與內容
- `styles.css`：桌機與手機版樣式
- `data.js`：路線、節點、官方來源與軌跡資料
- `app.js`：地圖、篩選、GPX 匯入／下載與互動功能
